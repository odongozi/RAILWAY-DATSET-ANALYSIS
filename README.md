 Railway Data Analysis

Project Overview

This project analyzes railway ticket and journey data to understand sales performance, passenger behavior, journey delays, and refund requests.

 Dataset

The dataset contains information about railway transactions, including purchase date and time, purchase type, payment method, railcard, ticket type, price, departure station, arrival destination, journey times, journey status, delay reasons, and refund requests.

 Objectives

* Analyze railway ticket sales and revenue
* Identify popular ticket types and payment methods
* Analyze passenger journey patterns
* Examine delays and their main causes
* Analyze refund requests
* Identify useful insights that can support better railway operations and customer service

Key Analysis Questions

* What is the total revenue generated?
* Which ticket type is most popular?
* Which stations have the highest number of journeys?
* What are the most common reasons for delays?
* How many journeys were delayed?
* How many customers requested refunds?
* Which payment method is most commonly used?

Tools Used

* Excel

Project Outcome

The analysis provides insights into railway sales, passenger journeys, delays, and refund patterns. These insights can help identify areas for improving operational efficiency and passenger experience.
